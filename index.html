O que é Criptografia de Letras?

A criptografia é uma técnica utilizada para transformar informações, dificultando sua leitura por pessoas não autorizadas. Um dos métodos mais antigos é a Cifra de César, que utiliza a substituição de letras.

Como funciona? Cada letra do texto original é deslocada três posições no alfabeto. Por exemplo: A vira D, B vira E, C vira F e Z vira C.

Este protótipo tem finalidade educativa e não deve ser utilizado para proteger informações confidenciais.

Explicação do Código Desenvolvido

Para desenvolver este protótipo, utilizamos JavaScript para implementar a lógica da Cifra de César.

  • Capturamos o texto digitado usando getElementById().
  • Convertemos as letras para maiúsculas.
  • Percorremos os caracteres utilizando um laço de repetição for.
  • Deslocamos cada letra três posições no alfabeto.
  • Utilizamos o operador de resto da divisão para retornar ao início do alfabeto quando necessário.
  • Mantemos espaços, números e sinais de pontuação.
  • Exibimos o resultado dinamicamente na página.
